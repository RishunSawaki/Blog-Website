# Building the blog skeleton

## Why this shape

The site is designed around locale-prefixed routes, filesystem-backed posts, and server-rendered MDX.

## Route map

- `/en` or `/ja` for the homepage
- `/en/posts/[slug]` for articles
- `/en/search` for full-text discovery

## Example code

```ts
export function routeFor(locale: "en" | "ja", slug: string) {
  return `/${locale}/posts/${slug}`;
}
```

## Next step

The same base can be extended with drafts, authentication, or a CMS later.
